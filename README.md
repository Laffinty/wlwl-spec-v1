# WLWL 语言规范 v1.0

本仓库是 **WLWL 编程语言的 v1.0 规范体系**。它是一套**独立**的规范性文档,与参考实现分处两仓,面向"规范即法律"的目标编写:每条陈述要么是必须满足的约束,要么被明确标为非规范。

- **上游实现**:`Laffinty/wlwl`(基线提交 `99041ef`,2026-10-24,已发布 tag `v0.11.4`;含 v1.0 语义落地、一致性册 §5.4 的 13 条收敛与 V-01 / V-02 / V-04 / V-05 的取证守卫)
- **当前状态**:v1.0 全 11 册**已成稿**;规范性内容完整。**规范侧发布点:`v1.0.1`**(2026-10-24;`v1.0.0` 是 2026-10-22 的首个发布点,已发布不移动)。**v1.0.2 的规范文本已成稿**(2026-10-25):17 个新公共面成员(传输层 / 字节层 / `TO_INT` / `CAT` / `SCRIPT_PATH` / `TAKE_ERR` / `SLEEP_ASYNC`)+ §5.4 的 13 行状态订正与最小复现 + 状态列门禁 + 上游基线前移到 `v0.11.4`;⚠ **发布仍待实现侧 v0.12.0 的验证读数**(一致性册 §3.5 第 1 条:§0.9 的「实现状态」列不得有「未实现」或「部分」)。实现侧待办项见[总纲 §0.9](docs/spec/wlwl-v1.0-overview.md)的「实现状态」列与[一致性册 §5.4](docs/spec/wlwl-v1.0-conformance.md)的规范↔实现差异登记 —— 那里逐条给出「类别」「状态」「实测读数」与「收敛路线」;发布时**必须**在发布说明里显式列出「实现待收敛」的项(实现仓 `CHANGELOG.md` 的同名一节即该清单)
- **规范性**:本仓库全部 11 册构成 L-规范层;其它仓库的文档(agent 工作说明、`wlwl-skill`、ADR、偏差台账)属 L-实现注 / L-决策 / L-历史层,**不具规范性**

## v1.0 相对 v0.11 改了什么

全部语义变更登记在[总纲 §0.9](docs/spec/wlwl-v1.0-overview.md)。**未在该表出现的改动不构成语义变更**(措辞、拆分与合并不在此列)。影响面最大的一条是 `D-01`:

> **未消费的 `ERR` 不再被静默丢弃。** 任何被丢弃的未消费 `ERR` 产生 `E0103`;`LET(_, expr)` 是唯一的显式丢弃构造。

这条改动的设计依据、核验过程与已知代价,写在[审计处置表 §3](docs/audit/audit-disposition.md)。

## 本仓库的体例

- **标点**:`,` `:` `;` `()` `[]` 用半角;`。` `、` `「」` `——` 用全角。**不用**全角逗号、冒号、分号与圆括号。
- **章节号**:`## N 标题` / `### N.M 标题`,手工编号,不用 Markdown 自动编号。
- **规范用语**:`**必须**` `**不得**` `**应当**` `**可以**`,含义按 RFC 2119。
- **实现注**:以 `**实现注(非规范)**` 起首,独立成段,不与规范条款同段。
- **引用**:同册写 `(§8.2)`;跨册写册名加节号,例:"语言核心册 §8.2"。
- **示例**:`wlwl` 围栏,`//` 注释标出求值结果;文法块用无标记围栏。示例块必须能在参考实现上跑通(退出码 0)。

## 变更本仓库

1. 规范文本的变更走[一致性册 §3](docs/spec/wlwl-v1.0-conformance.md)的版本规则;
2. 每次变更**必须**同步更新总纲 §0.9 的差异表;
3. 新增册**必须**同步更新总纲 §0.1 的册表与 §0.6 的规范矩阵;
4. 发布前**必须**通过[一致性册 §6.1](docs/spec/wlwl-v1.0-conformance.md)的文本检查(第 1–9 项),全部可脚本化。

## 自检

```
python script/check_spec.py --impl <参考实现的 wlwl 可执行文件>
python script/negctl.py --impl <参考实现的 wlwl 可执行文件>
```

`check_spec.py` 执行八项检查并分「错误 / 提示」两级输出;`negctl.py` 是**阴性对照** —— 向副本注入已知故障,要求检查器逐条报错。检查器自己的绿灯不成立时,`negctl.py` 会红。

当前读数(2026-10-25,上游基线 `v0.11.4` / `99041ef`):**错误 0 / 提示 0**,**65** 个 `wlwl` 示例块逐个跑通,阴性对照 **14/14** 命中(13 项注入 + 1 项提取口径自检)。
